# Security policy

## Supported versions
Only the [latest release](https://github.com/Arif1221/kairos-online/releases/latest) receives fixes.

## Reporting a vulnerability
Please do not open a public issue for security problems. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. You will get a reply within a week.

## Verifying a download
Official builds are published only on this repository's Releases page and on Google Play. GitHub releases from 0.7.6 onward are signed with this key (SHA-256 certificate fingerprint); Google Play builds are signed by Google:

```
87:F3:B8:92:D7:AE:57:0A:EC:B8:9D:26:A2:35:08:08:25:06:FF:0F:D2:CC:6B:B9:24:A1:DB:8C:95:05:0C:17
```

Builds from before 0.7.6 used a key that was published in the repository; do not trust APKs signed with it.
